#### **Media Sosial**
- Facebook Marketplace
- Instagram #tanahdijual #ruko
- Grup Facebook properti lokal

### 1.2 Kriteria Pencarian Lokasi

#### **Filter di Portal Properti**
```
Jenis Properti: Tanah / Ruko / Gedung Komersial
Lokasi: [Kota/Kabupaten target]
Harga: Rp200 juta - Rp1 miliar
Luas Tanah: Minimal 150 m²
Luas Bangunan: Minimal 100 m²
Kondisi: Baru / Bagus
Sertifikat: SHM / SHGB
```

#### **Lokasi Target yang Dicari**
1. **Dekat Perumahan Padat**
   - Radius 500m dari pemukiman
   - Minimal 500 KK di sekitar
   - Akses mudah dari perumahan

2. **Traffic Kendaraan Tinggi**
   - Jalan utama atau perempatan
   - Minimal 1.000 kendaraan/hari
   - Bisa dilewati mobil dan motor

3. **Akses Mudah**
   - Jalan minimal 2 mobil lewat
   - Parkir memadai
   - Tidak ada genangan/banjir

### 1.3 Langkah Pencarian Online

#### **Langkah 1: Buka Portal Properti**
```
1. Buka rumah123.com atau olx.co.id
2. Pilih kategori "Properti Komersial" atau "Tanah"
3. Masukkan lokasi target
4. Atur filter sesuai kriteria
5. Klik "Cari"
```

#### **Langkah 2: Review Hasil Pencarian**
```
Untuk setiap listing, cek:
□ Foto properti (jelas dan lengkap)
□ Harga (sesuai budget)
□ Luas tanah/bangunan (minimal 150 m²)
□ Lokasi (dekat perumahan?)
□ Sertifikat (SHM/SHGB)
□ Deskripsi lengkap
□ Kontak penjual
```

#### **Langkah 3: Kumpulkan Data**
Untuk setiap properti potensial, catat:
```
Nama Listing: _______________
Harga: Rp____________
Luas Tanah: ______________ m²
Luas Bangunan: ______________ m²
Lokasi: ______________
Sertifikat: ______________
Penjual: ______________
Kontak: ______________
Link: ______________
```

### 1.4 Checklist Lokasi Online

#### **Fisik Lokasi**
- [ ] Luas tanah minimal 150 m²
- [ ] Lebar minimal 12m
- [ ] Kondisi bangunan baik atau bisa direnovasi
- [ ] Tidak ada genangan/banjir
- [ ] Akses mudah untuk mobil

#### **Lokasi Strategis**
- [ ] Dekat perumahan (radius 500m)
- [ ] Traffic kendaraan >1.000/hari
- [ ] Tidak jauh dari jalan utama
- [ ] Mudah dilihat dari jalan

#### **Legalitas**
- [ ] Sertifikat lengkap (SHM/SHGB)
- [ ] Tidak ada sengketa
- [ ] Izin usaha bisa didapatkan
- [ ] Pajak PBB lunas

## TAHAP 3: Nego Harga dengan Penjual (2-4 minggu)

### 3.1 Strategi Nego Harga

#### **Sebelum Nego**
1. **Riset Harga Pasar**
   - Cek harga properti sejenis di sekitar
   - Bandingkan dengan listing lain
   - Hitung harga per meter persegi
   - Ketahui harga wajar

2. **Ketahui Motif Penjual**
   - Kenapa dijual? (butuh uang, pindah, dll)
   - Sudah berapa lama dijual?
   - Ada penawaran lain?
   - Urgensi penjual

3. **Siapkan Data**
   - Data properti lengkap
   - Bukti harga pasar
   - Rencana bisnis
   - Bukti kemampuan finansial

### 3.2 Teknik Nego Harga

#### **Teknik 1: Anchor Harga Rendah**
```
Penjual: "Harga Rp500 juta"
Anda: "Saya lihat harga pasaran di sekitar Rp350-400 juta. 
       Apakah ada fleksibilitas harga?"
```

#### **Teknik 2: Tukar Tambah**
```
Anda: "Jika saya bayar cash, bisa dapat diskon?"
Atau: "Jika saya ambil sekarang, harga bisa kurang?"
```

#### **Teknik 3: Kondisi Properti**
```
Anda: "Properti ini perlu renovasi sekitar Rp50 juta.
       Apakah harga bisa disesuaikan?"
```

#### **Teknik 4: Urgensi Penjual**
```
Anda: "Saya lihat properti ini sudah dijual cukup lama.
       Apakah ada pertimbangan harga?"
```

#### **Teknik 5: Tawaran Sekaligus**
```
Anda: "Saya bersedia bayar Rp400 juta cash dalam 1 minggu.
       Apakah bisa?"
```

### 3.3 Template Nego Harga

#### **Template WhatsApp/Telepon**
```
Selamat [pagi/siang/sore] Bapak/Ibu [Nama],

Saya [Nama], tertarik dengan properti di [Alamat] 
yang dijual Rp[Harga].

Setelah survei dan riset, saya ingin menawarkan:
- Harga: Rp[Harga tawaran]
- Pembayaran: [Cash/Cicilan]
- Waktu: [Durasi]

Alasan:
1. Kondisi properti perlu renovasi sekitar Rp[Angka]
2. Harga pasaran di sekitar Rp[Angka]
3. Saya serius ingin membeli

Apakah ada fleksibilitas harga?

Terima kasih.
```

### 3.4 Checklist Nego

#### **Sebelum Nego**
- [ ] Riset harga pasaran
- [ ] Ketahui motif penjual
- [ ] Siapkan data properti
- [ ] Siapkan bukti kemampuan finansial
- [ ] Tentukan harga maksimal

#### **Saat Nego**
- [ ] Dengarkan penjual
- [ ] Jangan langsung terima harga
- [ ] Ajukan pertanyaan
- [ ] Catat semua yang disepakati
- [ ] Minta waktu untuk pikirkan

#### **Setelah Nego**
- [ ] Konfirmasi kesepakatan tertulis
- [ ] Minta data properti lengkap
- [ ] Siapkan uang muka
- [ ] Hubungi notaris

## TAHAP 4: Beli/Sewa Properti (1-2 minggu)

### 4.1 Proses Pembelian

#### **Langkah 1: Validasi Dokumen**
- [ ] Cek sertifikat asli (SHM/SHGB)
- [ ] Cek IMB/PBG
- [ ] Cek pajak PBB lunas
- [ ] Cek tidak ada sengketa
- [ ] Cek riwayat properti

#### **Langkah 2: Buat Akta Jual Beli (AJB)**
- [ ] Pilih notaris/PPAT
- [ ] Siapkan dokumen
- [ ] Buat AJB
- [ ] Bayar BPHTB (5% dari NJOP)
- [ ] Bayar PPh (2,5% dari harga jual)

#### **Langkah 3: Proses Balik Nama**
- [ ] Daftar ke BPN
- [ ] Bayar biaya balik nama
- [ ] Tunggu proses (1-2 bulan)
- [ ] Terima sertifikat baru

### 4.2 Proses Sewa

#### **Langkah 1: Negosiasi Kontrak**
- [ ] Tentukan harga sewa
- [ ] Tentukan durasi (minimal 5 tahun)
- [ ] Tentukan kenaikan sewa per tahun
- [ ] Tentukan uang muka
- [ ] Tentukan deposit

#### **Langkah 2: Buat Kontrak Sewa**
- [ ] Pilih notaris
- [ ] Buat kontrak sewa
- [ ] Daftar ke kelurahan
- [ ] Bayar pajak sewa

### 4.3 Checklist Pembelian

#### **Dokumen yang Harus Dimiliki**
- [ ] Sertifikat SHM/SHGB atas nama Anda
- [ ] AJB (Akta Jual Beli)
- [ ] IMB/PBG
- [ ] PBB lunas
- [ ] Surat tidak sengketa

#### **Biaya Pembelian**
- [ ] Harga properti
- [ ] BPHTB (5% dari NJOP)
- [ ] PPh (2,5% dari harga jual)
- [ ] Biaya notaris (1-2%)
- [ ] Biaya balik nama
- [ ] Biaya perizinan

## TAHAP 5: Buat Proposal untuk Bank (1-2 minggu)

### 5.1 Struktur Proposal

#### **Cover Proposal**
```
PROPOSAL PEMBIAYAAN FRANCHISE MINIMARKET

Diajukan oleh:
[Nama lengkap]
[Alamat]
[No. HP]

Diajukan ke:
[Nama Bank]
Cabang [Nama Cabang]

Tanggal: [Tanggal]
```

#### **Isi Proposal**

##### **1. Ringkasan Eksekutif (1 halaman)**
- Profil pemohon
- Rencana bisnis
- Kebutuhan pembiayaan
- Kemampuan mengembalikan

##### **2. Profil Pemohon (1-2 halaman)**
- Data diri lengkap
- Pekerjaan dan penghasilan
- Pengalaman bisnis
- Riwayat kredit

##### **3. Rencana Bisnis (2-3 halaman)**
- Jenis usaha (franchise minimarket)
- Lokasi usaha
- Target pasar
- Strategi pemasaran
- Proyeksi keuntungan

##### **4. Analisis Keuangan (2-3 halaman)**
- Modal yang dibutuhkan
- Sumber pembiayaan
- Proyeksi omzet 3 tahun
- Proyeksi laba rugi 3 tahun
- Proyeksi arus kas 3 tahun
- Analisis break-even

##### **5. Rencana Penggunaan Dana (1 halaman)**
- Pembelian properti
- Renovasi
- Peralatan
- Stok awal
- Modal kerja

##### **6. Rencana Pengembalian (1 halaman)**
- Sumber pengembalian
- Jadwal cicilan
- Kemampuan bayar
- Rencana cadangan

##### **7. Lampiran (Beberapa halaman)**
- KTP, KK, NPWP
- Slip gaji 3 bulan
- Rekening koran 6 bulan
- Bukti kepemilikan properti
- Surat izin usaha
- Data franchise

### 5.3 Tips Membuat Proposal

#### **Tips Agar Proposal Diterima**
1. **Data Akurat**
   - Pastikan semua angka akurat
   - Sertakan bukti pendukung
   - Jangan melebih-lebihkan

2. **Analisis Realistis**
   - Proyeksi konservatif
   - Pertimbangkan risiko
   - Sertakan rencana cadangan

3. **Profesional**
   - Gunakan bahasa formal
   - Susun rapi dan sistematis
   - Sertakan tabel dan grafik

4. **Lengkapi**
   - Sertakan semua dokumen
   - Jangan ada yang terlewat
   - Foto-foto pendukung

### 6.2 Proses Pengajuan

#### **Langkah 1: Kunjungi Bank**
```
1. Datang ke kantor cabang bank
2. Temui customer service
3. Sampaikan ingin mengajukan KUR
4. Minta formulir pengajuan
5. Isi formulir dengan lengkap
```

#### **Langkah 2: Serahkan Dokumen**
```
1. Serahkan semua dokumen
2. Minta tanda terima
3. Tanya proses selanjutnya
4. Catat nama petugas
5. Minta nomor telepon yang bisa dihubungi
```

#### **Langkah 3: Tunggu Proses**
```
1. Wawancara oleh petugas (1-2 minggu)
2. Survei lokasi usaha (1 minggu)
3. Verifikasi data (1 minggu)
4. Keputusan (1-2 minggu)
5. Pencairan dana (1-2 hari)
```

### 6.3 Tips Agar KUR Disetujui

#### **Tips Penting**
1. **Usaha Sudah Berjalan**
   - Minimal 6 bulan berjalan
   - Ada bukti transaksi
   - Ada catatan keuangan

2. **Lokasi Strategis**
   - Sudah diverifikasi franchise
   - Traffic tinggi
   - Potensi omzet besar

3. **Rencana Bisnis Matang**
   - Proposal lengkap dan realistis
   - Analisis keuangan akurat
   - Rencana pengembalian jelas

4. **Riwayat Kredit Baik**
   - Tidak ada tunggakan
   - Rekening aktif
   - Transaksi lancar

5. **Siap Agunan**
   - SHM/SHGB properti
   - BPKB kendaraan
   - Jaminan lain

## Tips Sukses Franchise Minimarket

### Tips Keuangan
1. **Pisahkan Keuangan**
   - Rekening bisnis terpisah
   - Catat semua transaksi
   - Pantau arus kas

2. **Manajemen Stok**
   - Jangan stok berlebih
   - Pantau barang cepat laku
   - Hindari expired date

3. **Kontrol Biaya**
   - Optimasi jam kerja karyawan
   - Hemat listrik dan air
   - Negosiasi dengan supplier

### Tips Operasional
1. **Pelayanan Pelanggan**
   - Ramah dan cepat
   - Bersih dan rapi
   - Harga bersaing

2. **Manajemen Karyawan**
   - Latih dengan baik
   - Berikan insentif
   - Pantau kinerja

3. **Marketing**
   - Promo rutin
   - Media sosial
   - Loyalitas pelanggan

### Tips Ekspansi
1. **Scale Up**
   - Setelah berhasil 1 tahun
   - Ajukan KUR lagi
   - Buka gerai kedua

2. **Diversifikasi**
   - Tambah layanan
   - Jual produk unik
   - Kerjasama dengan pihak lain
