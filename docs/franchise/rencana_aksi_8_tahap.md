# Rencana Aksi 8 TAHAP: Strategi SEWA Franchise Minimarket

## Ringkasan Strategi

**Prinsip**: SEWA dulu, passive income tebal, asset nanti aja!

**Target**: Rp12-22 juta/bulan passive income dari franchise minimarket

**Modal**: Rp480 juta (100% dari bank + modal sendiri Rp80 juta)

---

## TAHAP 1: Riset Lokasi Sewa (2-4 minggu)

### Tujuan
Menemukan lokasi sewa strategis untuk franchise minimarket

### Langkah-Langkah

#### 1.1 Buka Portal Properti
- [ ] Buka Rumah123.com
- [ ] Buka OLX.co.id
- [ ] Buka Lamudi.co.id
- [ ] Buka Facebook Marketplace

#### 1.2 Filter Pencarian
```
Kategori: Ruko / Ruang Usaha / Tanah Komersial
Lokasi: [Kota target]
Harga Sewa: Rp3-10 juta/bulan
Luas: Minimal 100m²
Kondisi: Siap pakai
```

#### 1.3 Kriteria Lokasi
- [ ] Dekat perumahan padat (radius 500m)
- [ ] Traffic kendaraan >1.000/hari
- [ ] Akses mudah untuk mobil
- [ ] Parkir memadai
- [ ] Tidak ada genangan/banjir

#### 1.4 Kumpulkan Data
Untuk setiap lokasi potensial, catat:
- Alamat lengkap
- Luas tanah/bangunan
- Harga sewa/bulan
- Fasilitas yang termasuk
- Kontak pemilik

### Target Mingguan

| Minggu | Target |
|--------|--------|
| 1 | Kumpulkan 10 listing |
| 2 | Hubungi 5 pemilik |
| 3 | Kunjungi 3-5 lokasi |
| 4 | Pilih 2 lokasi terbaik |

## TAHAP 3: Nego Harga Sewa (1-2 minggu)

### Tujuan
Mendapatkan harga sewa terbaik untuk lokasi yang dipilih

### Langkah-Langkah

#### 3.1 Riset Harga Pasar
- [ ] Cek harga sewa sejenis di sekitar
- [ ] Bandingkan dengan listing lain
- [ ] Ketahui harga wajar

#### 3.2 Strategi Nego

##### Teknik 1: Bayar Tahunan untuk Diskon
```
Anda: "Jika saya bayar sewa 1 tahun di muka, bisa dapat diskon?"
```

##### Teknik 2: Kontrak Panjang
```
Anda: "Jika saya sewa 2-3 tahun, harga bisa kurang?"
```

##### Teknik 3: Kondisi Properti
```
Anda: "Properti ini perlu renovasi kecil. Apakah harga bisa disesuaikan?"
```

##### Teknik 4: Urgensi
```
Anda: "Saya butuh lokasi ini segera. Jika harga cocok, saya langsung ambil."
```

#### 3.3 Finalisasi Harga
- [ ] Buat kesepakatan tertulis
- [ ] Minta diskon untuk bayar di muka
- [ ] Tentukan durasi kontrak
- [ ] Buat kontrak sewa

### Target Harga Sewa

| Lokasi | Target Sewa | Strategi |
|--------|-------------|----------|
| Kota Kecil | Rp5-8 juta/bulan | Bayar 1 tahun di muka |
| Kota Menengah | Rp10-15 juta/bulan | Kontrak 2 tahun |
| Kota Besar | Rp20-30 juta/bulan | Nego keras |

### Template Nego

```
Selamat [pagi/siang/sore] Bapak/Ibu [Nama],

Saya [Nama], tertarik dengan properti di [Alamat]
yang disewakan Rp[Harga]/bulan.

Setelah survei, saya ingin menawarkan:
- Sewa: Rp[Harga tawaran]/bulan
- Durasi: [Durasi] tahun
- Pembayaran: [Di muka/bulanan]

Alasan:
1. Properti perlu renovasi kecil
2. Harga pasaran di sekitar Rp[Angka]/bulan
3. Saya serius ingin menyewa

Apakah ada fleksibilitas harga?

Terima kasih.
```

## TAHAP 6: Persiapan Gerai (1-2 bulan)

### Tujuan
Menyiapkan gerai sesuai standar franchise

### Langkah-Langkah

#### 6.1 Renovasi
- [ ] Desain interior sesuai standar franchise
- [ ] Pasang rak-rak
- [ ] Instalasi listrik dan air
- [ ] Pasang AC/kipas
- [ ] Finishing cat dan dekorasi

#### 6.2 Peralatan
- [ ] Kasir (POS system)
- [ ] Kulkas dan freezer
- [ ] Rak display
- [ ] Brankas
- [ ] CCTV
- [ ] Printer struk
- [ ] Timbangan

#### 6.3 Rekrutmen Karyawan
- [ ] Kepala toko (1 orang)
- [ ] Kasir (2-3 orang)
- [ ] Pramuniaga (2-3 orang)
- [ ] Staf gudang (1 orang)

#### 6.4 Stok Awal
- [ ] Pesan stok awal dari supplier
- [ ] Terima dan cek barang
- [ ] Input data ke sistem
- [ ] Susun di rak
- [ ] Siapkan display

#### 6.5 Dokumen Gerai
- [ ] Surat izin usaha (IUMK)
- [ ] Nomor induk usaha
- [ ] NPWP usaha
- [ ] Asuransi usaha

### Timeline Persiapan

| Minggu | Kegiatan |
|--------|----------|
| 1 | Mulai renovasi |
| 2 | Selesai renovasi, pasang peralatan |
| 3 | Rekrut dan latih karyawan |
| 4 | Stok awal, siap operasional |

- [ ] Pantau omzet harian

- [ ] Terima masukan pelanggan
- [ ] Sesuaikan strategi jika perlu

- [ ] Evaluasi omzet bulanan
- [ ] Analisis laba rugi
- [ ] Optimasi biaya operasional
- [ ] Tingkatkan pelayanan
- [ ] Rencanakan promosi bulan depan

- [ ] Evaluasi kinerja 1 tahun
- [ ] Analisis profitabilitas
- [ ] Rencana ekspansi

## Tips Sukses

### Tips Keuangan
1. **Pisahkan Keuangan** - Rekening bisnis terpisah
2. **Catat Semua Transaksi** - Pantau arus kas
3. **Hindari Hutang Konsumtif** - Fokus pada bisnis

### Tips Operasional
1. **Pelayanan Pelanggan** - Ramah dan cepat
2. **Manajemen Stok** - Jangan kehabisan barang
3. **Kontrol Biaya** - Hemat tapi kualitas tetap

### Tips Scale Up
1. **Tunggu Stabil** - Minimal 1 tahun
2. **Siapkan Modal** - Ajukan KUR lagi
3. **Pilih Lokasi Baru** - Riset matang
