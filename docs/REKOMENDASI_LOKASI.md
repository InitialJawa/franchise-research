## 5 Aspek Evaluasi Tim Surveyor Alfamart

Berdasarkan dokumen resmi Alfamart, tim surveyor akan mengevaluasi 5 aspek utama:

| No | Aspek | Sumber Data | Target Minimum |
|----|-------|-------------|----------------|
| 1 | **Jumlah Penduduk** | Data BPS/Dukcapil | >50.000 jiwa radius 1km |

| 3 | **Traffic Kendaraan** | Manual count / Google Maps | >500 kendaraan/hari |
| 4 | **Kompetitor** | Survei langsung | <3 Alfamart/Indomaret dalam 2km |

## OPEX Bulanan Alfamart (Standar)

| Komponen | Rp/Bulan |
|----------|----------|
| Gaji 4 karyawan | 12.000.000 |
| Sewa toko | 5.000.000 |
| Listrik | 1.500.000 |
| Internet | 300.000 |
| Air | 200.000 |
| Promosi | 500.000 |
| ATK | 200.000 |
| Konsumsi | 300.000 |
| Pajak | 300.000 |
| Lain-lain | 500.000 |
| **TOTAL** | **Rp20.800.000** |

## Rumus BEP Alfamart

```
BEP (Bulan) = Total Modal ÷ (Laba Kotor - OPEX)

Dimana:
- Laba Kotor = Omzet × 10% (margin Alfamart)
- OPEX = Rp20-25 juta/bulan (tergantung lokasi)

Contoh:
- Modal: Rp400 juta
- Omzet: Rp150 juta/bulan
- Laba Kotor: Rp15 juta/bulan
- OPEX: Rp23 juta/bulan
- Rugi: -Rp8 juta/bulan
- BEP: TIDAK ADA (perlu omzet >Rp230 juta/bulan)
```
