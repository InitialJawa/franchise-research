# Panduan Nego Harga Properti

## Persiapan Nego

### 1. Riset Harga Pasar

#### **Cara Riset Harga**
1. **Portal Properti**
   - Cek harga properti sejenis di sekitar
   - Bandingkan dengan listing lain
   - Hitung harga per meter persegi

2. **Google Maps**
   - Cari properti sejenis di sekitar
   - Hubungi penjual untuk tanya harga
   - Catat data harga

3. **Bicara dengan Warga**
   - Tanyakan harga properti di sekitar
   - Tanyakan riwayat harga
   - Tanyakan kondisi pasar

#### **Template Riset Harga**
```
Lokasi: [Alamat]

Properti Sejenis:
1. [Alamat] - Rp[Angka]/m²
2. [Alamat] - Rp[Angka]/m²
3. [Alamat] - Rp[Angka]/m²

Rata-rata: Rp[Angka]/m²
Harga Wajar: Rp[Angka]/m²
```

### 2. Ketahui Motif Penjual

#### **Pertanyaan untuk Penjual**
1. "Kenapa properti ini dijual?"
2. "Sudah berapa lama dijual?"
3. "Ada penawaran lain?"
4. "Urgensi penjual?"
5. "Bisa nego harga?"

#### **Motif Penjual dan Strategi**
| Motif | Strategi Nego |
|-------|---------------|
| Butuh uang cepat | Tawar lebih rendah, bayar cash |
| Pindah domisili | Tawar dengan harga wajar |
| Properti tidak terpakai | Tawar lebih rendah |
| Investasi | Tawar dengan harga pasar |
| Warisan | Hati-hati, cek legalitas |

### 3. Siapkan Data

#### **Data yang Perlu Disiapkan**
1. **Data Properti**
   - Foto-foto properti
   - Data luas tanah/bangunan
   - Data legalitas

2. **Data Harga Pasar**
   - Harga properti sejenis
   - Harga per m²
   - Tren harga

3. **Data Kemampuan Finansial**
   - Bukti tabungan
   - Bukti penghasilan
   - Rencana pembayaran

## Teknik Nego Harga

### Teknik 1: Anchor Harga Rendah

#### **Cara Melakukan**
1. **Mulai dengan Harga Rendah**
   ```
   Penjual: "Harga Rp500 juta"
   Anda: "Saya lihat harga pasaran di sekitar Rp350-400 juta. 
          Apakah ada fleksibilitas harga?"
   ```

2. **Dasarkan Harga Rendah**
   - Harga pasaran
   - Kondisi properti
   - Biaya renovasi

3. **Naikkan Bertahap**
   - Jangan langsung terima
   - Naikkan sedikit demi sedikit
   - Tetap di bawah harga jual

#### **Contoh Dialog**
```
Penjual: "Harga Rp500 juta"
Anda: "Saya tawar Rp350 juta"
Penjual: "Terlalu rendah, minimal Rp450 juta"
Anda: "Saya bisa naikkan jadi Rp375 juta"
Penjual: "Minimal Rp425 juta"
Anda: "Rp400 juta cash dalam 1 minggu"
Penjual: "Deal!"
```

### Teknik 2: Tukar Tambah

#### **Cara Melakukan**
1. **Tawar Cash untuk Diskon**
   ```
   Anda: "Jika saya bayar cash, bisa dapat diskon?"
   ```

2. **Tawar Bayar Sekaligus**
   ```
   Anda: "Jika saya ambil sekarang, harga bisa kurang?"
   ```

3. **Tawar Bayar Cepat**
   ```
   Anda: "Saya bisa bayar dalam 1 minggu, harga bisa kurang?"
   ```

#### **Contoh Dialog**
```
Penjual: "Harga Rp500 juta"
Anda: "Jika saya bayar cash minggu ini, harga bisa kurang?"
Penjual: "Bisa, saya kasih diskon Rp25 juta"
Anda: "Rp475 juta cash minggu ini, deal?"
Penjual: "Deal!"
```

### Teknik 3: Kondisi Properti

#### **Cara Melakukan**
1. **Tunjukkan Kekurangan**
   ```
   Anda: "Properti ini perlu renovasi sekitar Rp50 juta.
          Apakah harga bisa disesuaikan?"
   ```

2. **Hitung Biaya Renovasi**
   - Catat semua kekurangan
   - Hitung biaya perbaikan
   - Tawarkan harga lebih rendah

3. **Gunakan Data Renovasi**
   ```
   Anda: "Berdasarkan survei, properti ini perlu:
          - Renovasi atap: Rp15 juta
          - Perbaikan listrik: Rp10 juta
          - Cat ulang: Rp10 juta
          Total: Rp35 juta
          Apakah harga bisa kurang Rp35 juta?"
   ```

#### **Contoh Dialog**
```
Penjual: "Harga Rp500 juta"
Anda: "Properti ini perlu renovasi Rp50 juta. 
       Apakah harga bisa Rp450 juta?"
Penjual: "Saya bisa kasih Rp475 juta"
Anda: "Rp460 juta, cash minggu ini"
Penjual: "Deal!"
```

### Teknik 4: Urgensi Penjual

#### **Cara Melakukan**
1. **Tanya Sudah Berapa Lama Dijual**
   ```
   Anda: "Properti ini sudah berapa lama dijual?"
   ```

2. **Tanya Ada Penawaran Lain**
   ```
   Anda: "Sudah ada yang menawar?"
   ```

3. **Manfaatkan Urgensi**
   ```
   Anda: "Saya lihat properti ini sudah dijual cukup lama.
          Apakah ada pertimbangan harga?"
   ```

#### **Contoh Dialog**
```
Anda: "Properti ini sudah berapa lama dijual?"
Penjual: "Sudah 6 bulan"
Anda: "Apakah sudah ada penawaran?"
Penjual: "Belum ada yang cocok"
Anda: "Saya serius ingin membeli, tapi harga harus sesuai
       dengan kondisi properti. Rp400 juta cash, deal?"
Penjual: "Bisa, deal!"
```

### Teknik 5: Tawaran Sekaligus

#### **Cara Melakukan**
1. **Tawar Harga Tetap**
   ```
   Anda: "Saya bersedia bayar Rp400 juta cash dalam 1 minggu.
          Apakah bisa?"
   ```

2. **Tawar dengan Deadline**
   ```
   Anda: "Harga Rp400 juta, cash dalam 3 hari.
          Jika tidak, saya cari lokasi lain."
   ```

3. **Tawar dengan Kondisi**
   ```
   Anda: "Rp400 juta cash, asalkan dokumen lengkap
          dan bisa balik nama minggu ini."
   ```

#### **Contoh Dialog**
```
Penjual: "Harga Rp500 juta"
Anda: "Saya tawar Rp400 juta cash dalam 1 minggu"
Penjual: "Terlalu rendah"
Anda: "Itu harga final saya. Jika tidak, saya cari lokasi lain"
Penjual: "Bisa Rp420 juta?"
Anda: "Rp410 juta, cash besok"
Penjual: "Deal!"
```

## Strategi Nego Lanjutan

### 1. Gunakan Tekanan Waktu

#### **Cara Melakukan**
1. **Buat Deadline**
   ```
   Anda: "Saya harus putuskan minggu ini. Apakah harga bisa kurang?"
   ```

2. **Tunjukkan Alternatif**
   ```
   Anda: "Saya juga lihat properti lain yang lebih murah.
          Apakah bisa menyesuaikan?"
   ```

3. **Buat Urgensi**
   ```
   Anda: "Saya butuh properti ini untuk usaha. 
          Jika harga cocok, saya ambil sekarang."
   ```

### 2. Gunakan leverage Finansial

#### **Cara Melakukan**
1. **Tunjukkan Kemampuan Bayar**
   ```
   Anda: "Saya bisa bayar cash. Apakah ada diskon?"
   ```

2. **Tunjukkan Bukti Tabungan**
   ```
   Anda: "Saya punya tabungan Rp500 juta. 
          Jika harga cocok, saya bayar sekarang."
   ```

3. **Tunjukkan Penghasilan**
   ```
   Anda: "Saya punya penghasilan tetap Rp15 juta/bulan.
          Saya mampu bayar cicilan jika perlu."
   ```

### 3. Gunakan Tekanan Sosial

#### **Cara Melakukan**
1. **Libatkan Keluarga**
   ```
   Anda: "Istri saya setuju dengan harga Rp400 juta.
          Jika lebih, saya harus minta izin lagi."
   ```

2. **Tunjukkan Keseriusan**
   ```
   Anda: "Saya sudah bawa uang muka Rp50 juta.
          Jika harga cocok, saya bayar sekarang."
   ```

3. **Buat Komitmen**
   ```
   Anda: "Saya sudah rencanakan usaha di lokasi ini.
          Jika harga cocok, saya langsung mulai."
   ```

## Tips Nego Harga

### Tips Sukses

#### **1. Jangan Terburu-buru**
- Dengarkan penjual
- Jangan langsung terima harga
- Ambil waktu untuk pikirkan

#### **2. Selalu Nego**
- Jangan pernah terima harga awal
- Selalu tawar lebih rendah
- Naikkan bertahap

#### **3. Gunakan Data**
- Dasarkan nego dengan data
- Tunjukkan harga pasar
- Hitung biaya renovasi

#### **4. Tunjukkan Keseriusan**
- Bawa uang muka
- Siapkan dokumen
- Tunjukkan kemampuan bayar

#### **5. Bersedia Pergi**
- Jangan terlalu tertarik
- Tunjukkan alternatif
- Bersedia cari lokasi lain

### Kesalahan yang Harus Dihindari

#### **1. Terlalu Tertarik**
- Jangan tunjukkan antusiasme berlebihan
- Jangan langsung terima harga
- Jangan buru-buru putuskan

#### **2. Nego Terlalu Rendah**
- Jangan tawar terlalu rendah
- Hormati penjual
- Realistis dengan harga

#### **3. Tidak Siap Data**
- Jangan nego tanpa data
- Siapkan harga pasar
- Siapkan bukti renovasi

#### **4. Tidak Ada Deadline**
- Buat deadline nego
- Jangan terlalu lama
- Putuskan dalam waktu wajar

#### **5. Tidak Ada Alternatif**
- Cari beberapa lokasi
- Jangan terpaku pada 1 lokasi
- Siapkan plan B

## Contoh Kasus Nego

### Kasus 1: Harga Tinggi, Kondisi Kurang Baik

#### **Situasi**
- Harga jual: Rp500 juta
- Kondisi: Perlu renovasi Rp50 juta
- Harga pasaran: Rp400-450 juta

#### **Strategi**
1. Tawar Rp350 juta (anchor rendah)
2. Tunjukkan biaya renovasi
3. Naikkan bertahap sampai Rp400 juta
4. Bayar cash untuk diskon

#### **Hasil**
- Harga akhir: Rp400 juta
- Cash dalam 1 minggu
- Hemat Rp100 juta

### Kasus 2: Penjual Butuh Uang Cepat

#### **Situasi**
- Harga jual: Rp500 juta
- Penjual butuh uang cepat
- Belum ada penawaran lain

#### **Strategi**
1. Tawar Rp350 juta (anchor rendah)
2. Tunjukkan kemampuan bayar cash
3. Buat deadline 1 minggu
4. Nego sampai Rp400 juta

#### **Hasil**
- Harga akhir: Rp400 juta
- Cash dalam 1 minggu
- Hemat Rp100 juta

### Kasus 3: Properti Sudah Lama Dijual

#### **Situasi**
- Harga jual: Rp500 juta
- Sudah dijual 1 tahun
- Belum ada penawaran

#### **Strategi**
1. Tanyakan sudah berapa lama dijual
2. Tanya ada penawaran lain
3. Tawar Rp350 juta (anchor rendah)
4. Nego sampai Rp400 juta

#### **Hasil**
- Harga akhir: Rp400 juta
- Cash dalam 1 minggu
- Hemat Rp100 juta
