## Checklist Kriteria Lokasi

### Fisik Lokasi
- [ ] Luas tanah minimal 150 m²
- [ ] Lebar minimal 12m
- [ ] Kondisi bangunan baik atau bisa direnovasi
- [ ] Tidak ada genangan/banjir
- [ ] Akses mudah untuk mobil

### Lokasi Strategis
- [ ] Dekat perumahan (radius 500m)
- [ ] Traffic kendaraan >1.000/hari
- [ ] Tidak jauh dari jalan utama
- [ ] Mudah dilihat dari jalan
- [ ] Parkir memadai

### Legalitas
- [ ] Sertifikat lengkap (SHM/SHGB)
- [ ] Tidak ada sengketa
- [ ] Izin usaha bisa didapatkan
- [ ] Pajak PBB lunas
- [ ] IMB/PBG ada (jika ada bangunan)

### Kompetitor
- [ ] Jarak >500m dari Alfamart/Indomaret
- [ ] Tidak ada minimarket besar lain di sekitar
- [ ] Pasar tradisional bisa jadi pelengkap

## Langkah Pencarian Online

### Langkah 1: Buka Portal Properti
1. Buka rumah123.com atau olx.co.id
2. Pilih kategori "Properti Komersial" atau "Tanah"
3. Masukkan lokasi target
4. Atur filter sesuai kriteria
5. Klik "Cari"

### Langkah 2: Review Hasil Pencarian
Untuk setiap listing, cek:
- [ ] Foto properti (jelas dan lengkap)
- [ ] Harga (sesuai budget)
- [ ] Luas tanah/bangunan (minimal 150 m²)
- [ ] Lokasi (dekat perumahan?)
- [ ] Sertifikat (SHM/SHGB)
- [ ] Deskripsi lengkap
- [ ] Kontak penjual

### Langkah 3: Kumpulkan Data
Untuk setiap properti potensial, catat:
- [ ] Nama listing
- [ ] Harga
- [ ] Luas tanah/bangunan
- [ ] Lokasi lengkap
- [ ] Sertifikat
- [ ] Kontak penjual
- [ ] Link listing

### Langkah 4: Validasi Data
Untuk setiap properti potensial:
- [ ] Hubungi penjual
- [ ] Tanya ketersediaan
- [ ] Minta foto tambahan
- [ ] Minta alamat lengkap
- [ ] Rencanakan kunjungan

## Prioritas Lokasi

### Prioritas 1: Lokasi Ideal
- Luas tanah >200 m²
- Lebar >15m
- Dekat perumahan padat
- Traffic tinggi
- Tidak ada kompetitor
- Harga sesuai budget

### Prioritas 2: Lokasi Baik
- Luas tanah 150-200 m²
- Lebar 12-15m
- Dekat perumahan
- Traffic sedang
- Kompetitor jauh
- Harga bisa nego

### Prioritas 3: Lokasi Alternatif
- Luas tanah 150 m²
- Lebar 12m
- Bisa direnovasi
- Traffic cukup
- Kompetitor ada
- Harga murah

## Tips Pencarian Online

### Tips Efektif
1. **Gunakan Banyak Platform**
   - Jangan hanya 1 platform
   - Cek semua portal properti
   - Manfaatkan media sosial

2. **Filter dengan Ketat**
   - Jangan tergoda harga murah
   - Fokus pada kriteria utama
   - Eliminasi yang tidak sesuai

3. **Validasi Data**
   - Jangan percaya foto saja
   - Hubungi penjual
   - Kunjungi langsung

4. **Dokumentasi**
   - Foto semua properti
   - Catat data lengkap
   - Simpan link listing

### Kesalahan yang Harus Dihindari
1. **Terburu-buru**
   - Jangan langsung beli
   - Bandingkan beberapa lokasi
   - Validasi semua data

2. **Abai Legalitas**
   - Cek sertifikat
   - Pastikan tidak sengketa
   - Validasi pajak

3. **Abai Lokasi**
   - Jangan hanya lihat harga
   - Fokus pada traffic
   - Pertimbangkan kompetitor

## Rekomendasi Lokasi

### Kota-Kota Potensial
1. **Jabodetabek**
   - Tangerang, Bekasi, Depok, Bogor
   - Banyak perumahan baru
   - Harga masih terjangkau

2. **Kota Besar**
   - Surabaya, Bandung, Semarang
   - Pasar besar
   - Kompetisi ketat

3. **Kota Menengah**
   - Malang, Yogyakarta, Solo
   - Pasar berkembang
   - Kompetisi sedang

4. **Kota Kecil**
   - Kabupaten di Jawa
   - Kompetisi rendah
   - Pasar potensial

### Lokasi yang Harus Dihindari
1. **Area Banjir**
   - Riwayat banjir
   - Drainase buruk

2. **Lokasi Terpencil**
   - Jauh dari pemukiman
   - Traffic rendah

3. **Kompetitor Ketat**
   - Sudah ada 3+ minimarket
   - Pasar jenuh

4. **Legalitas Bermasalah**
   - Sengketa tanah
   - Izin sulit
