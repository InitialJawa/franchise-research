# Riset Bisnis — Franchise & Pertanian Greenhouse

Riset komprehensif untuk menentukan bisnis terbaik di Plosokerep, Sumberlawang, Sragen.

## Ringkasan Proyek

**Tujuan**: Membandingkan peluang bisnis franchise minimarket vs greenhouse pertanian untuk lokasi Plosokerep, Sragen, Jawa Tengah.

**Opsi yang Dianalisis:**
1. **Franchise Minimarket** (Alfamart) — modal besar, pendapatan stabil
2. **Greenhouse Melon Premium** — modal sedang, ROI tinggi, ekosistem sudah ada
3. **Greenhouse Cabai** — modal sedang, BEP cepat, cash flow rutin

## Franchise yang Dianalisis

| Brand | Modal Awal | Franchise Fee | Royalti | Balik Modal |
|-------|-----------|---------------|---------|-------------|
| **Alfamart** | Rp300-800 juta | Rp45 juta/5 thn | 0-4% | ~2-3 tahun |
| **Indomaret** | Rp394-1.4 miliar | Rp36 juta/5 thn | 0-4% | ~2-3 tahun |
| **O!Save** | Rp400-500 juta | Termasuk | 0% | Belum ada data |
| **Alfamidi** | Rp500 juta-1.5 miliar | Hubungi sales | 0-4% | ~3-4 tahun |

## Strategi Pembiayaan

### Opsi 1: KUR Mikro + Modal Sendiri
- Modal sendiri: Rp80 juta
- KUR Mikro: Rp80 juta (tanpa agunan)
- **Total: Rp160 juta**

### Opsi 2: KUR Mikro + KUR Kecil + Modal Sendiri
- Modal sendiri: Rp80 juta
- KUR Mikro: Rp100 juta (tanpa agunan)
- KUR Kecil: Rp200 juta (perlu agunan)
- **Total: Rp380 juta**

### Opsi 3: 100% dari Bank
- KUR Mikro: Rp100 juta (tanpa agunan)
- KUR Kecil: Rp300 juta (perlu agunan)
- **Total: Rp400 juta**

## Proyeksi Keuntungan

### Lokasi Perkotaan
- Omzet: Rp400-600 juta/bulan
- Laba bersih: Rp55-70 juta/bulan (margin 7-9%)
- Cicilan: Rp6-8 juta/bulan
- **Sisa keuntungan: Rp47-62 juta/bulan**

### Lokasi Pinggiran
- Omzet: Rp200-300 juta/bulan
- Laba bersih: Rp22-35 juta/bulan
- Cicilan: Rp6-8 juta/bulan
- **Sisa keuntungan: Rp14-27 juta/bulan**

## Cara Menggunakan

### Install Dependencies
```bash
pip install -r requirements.txt
```

### Jalankan Analisis
```bash

python run_analysis.py

# Atau jalankan individual
python scripts/compare_franchise.py
python scripts/simulasi_kur.py
python scripts/analisis_keuntungan.py
```

## Panduan Step-by-Step

### TAHAP 1: Riset Lokasi Online (2-4 minggu)
1. Buka portal properti (Rumah123, OLX, Lamudi)
2. Filter sesuai kriteria (luas >150m², harga Rp200j-1M)
3. Kumpulkan 20+ listing
4. Review dan filter 10 listing terbaik
5. Hubungi 5 penjual
6. Kunjungi 3-5 lokasi
7. Pilih 2-3 lokasi terbaik

### TAHAP 2: Submit Lokasi ke Franchise (1-2 minggu)
1. Siapkan foto dan data properti
2. Submit ke Alfamart/Indomaret/O!Save
3. Tunggu evaluasi franchise
4. Terima hasil evaluasi

### TAHAP 3: Nego Harga dengan Penjual (2-4 minggu)
1. Riset harga pasar
2. Ketahui motif penjual
3. Tawar dengan anchor rendah
4. Naikkan bertahap
5. Finalisasi harga

### TAHAP 4: Beli/Sewa Properti (1-2 minggu)
1. Validasi dokumen
2. Buat Akta Jual Beli (AJB)
3. Proses balik nama
4. Terima sertifikat

### TAHAP 5: Buat Proposal untuk Bank (1-2 minggu)
1. Siapkan profil pemohon
2. Buat rencana bisnis
3. Analisis keuangan
4. Rencana penggunaan dana
5. Rencana pengembalian

### TAHAP 6: Ajukan KUR ke Bank (2-4 minggu)
1. Kunjungi bank
2. Serahkan dokumen
3. Tunggu wawancara dan survei
4. Tunggu keputusan
5. Terima pencairan dana

### TAHAP 7: Persiapan Gerai (1-2 bulan)
1. Renovasi lokasi
2. Pengadaan peralatan
3. Rekrutmen karyawan
4. Stok awal

### TAHAP 8: Grand Opening!
1. Promosi grand opening
2. Mulai operasional
3. Monitoring awal
4. Evaluasi bulanan
